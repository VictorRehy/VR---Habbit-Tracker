# VR - Road to MIT

A self-contained, offline-first HTML web application designed for comprehensive habit and progress tracking. It uses vanilla JavaScript, zero dependencies, and stores all data locally in your browser.

## Getting Started

1. **Download:** Save the provided code as `vr-road-to-mit.html`.
2. **Open:** Simply double-click the file to open it in any modern browser (Chrome, Edge, Firefox, Safari). It runs locally via the `file://` protocol.
3. **Optional Server:** If you prefer a stable origin (to avoid `file://` storage quirks), you can serve it via Python:
   ```bash
   python -m http.server 5173
